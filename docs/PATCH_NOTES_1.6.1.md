# Liftly 1.6.1

## Sessão

- Todas as séries do treino permanecem visíveis para permitir planejamento.
- A próxima série continua destacada como `AGORA`; séries futuras são marcadas como planejadas.
- A carga digitada na primeira série de um exercício é copiada para séries seguintes que ainda estejam intactas.
- Séries concluídas ou já editadas manualmente não são sobrescritas.

## Bi-set

- O controle `Bi-set` volta a aparecer no editor da ficha.
- Dois exercícios consecutivos marcados como Bi-set/Supersérie formam um par A/B.
- A execução é intercalada por rodada: A1 → B1 → descanso → A2 → B2.
- A sessão identifica visualmente `BI-SET A` e `BI-SET B`.
